===========================================
TABLE: student_lead_activities
===========================================

PURPOSE:
Tracks all lead generation activities and form submissions. Captures detailed information about how, when, and where students found and engaged with the platform. Stores marketing attribution data (UTM parameters), device/browser information, IVR call details, and student background. One student can have multiple lead activities, with each activity representing a form submission or interaction event.

KEY BUSINESS RULES:
- One student can have multiple lead activities (form fills, calls, etc.)
- Tracks complete marketing attribution via UTM parameters
- Captures device, browser, and location data for analytics
- Stores IVR call recordings and duration
- Number of lead activities indicates student engagement level
- Tracks if lead was transferred between counsellors

===========================================

===========================================

===========================================
COMMON QUERY PATTERNS
===========================================

1. Get all activities for a student:
   SELECT * FROM student_lead_activities WHERE student_id = 'STU123' ORDER BY created_at DESC;

2. Find leads from specific source:
   SELECT * FROM student_lead_activities WHERE source = 'Facebook';

3. Track campaign performance:
   SELECT utm_campaign, COUNT(*) as lead_count
   FROM student_lead_activities GROUP BY utm_campaign;

4. Find mobile vs desktop leads:
   SELECT device, COUNT(*) as count
   FROM student_lead_activities GROUP BY device;

5. Get leads by CTA:
   SELECT cta_name, COUNT(*) as clicks
   FROM student_lead_activities GROUP BY cta_name ORDER BY clicks DESC;

6. Find leads from specific city:
   SELECT * FROM student_lead_activities WHERE ip_city = 'Mumbai';

7. Get working professionals:
   SELECT * FROM student_lead_activities WHERE working_professional = true;

8. Track browser usage:
   SELECT browser, COUNT(*) FROM student_lead_activities GROUP BY browser;

9. Find leads with IVR calls:
   SELECT * FROM student_lead_activities WHERE call_sid != '';

10. Get recent lead activities:
    SELECT * FROM student_lead_activities 
    WHERE created_at >= CURRENT_DATE - INTERVAL '7 days';

11. Find high-engagement students:
    SELECT student_id, COUNT(*) as activity_count
    FROM student_lead_activities 
    GROUP BY student_id 
    HAVING COUNT(*) > 1
    ORDER BY activity_count DESC;

12. Track UTM source performance:
    SELECT utm_source, utm_medium, COUNT(*) as leads
    FROM student_lead_activities 
    GROUP BY utm_source, utm_medium;

13. Find transferred leads:
    SELECT * FROM student_lead_activities WHERE is_transfered = true;

14. Get leads by qualification level:
    SELECT highest_qualification, COUNT(*) 
    FROM student_lead_activities 
    GROUP BY highest_qualification;
